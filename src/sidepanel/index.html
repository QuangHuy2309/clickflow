ClickFlow Click & type automation

Record your first flow

Press record and use the page as usual. Every click, text entry and selection becomes a step you can replay.

    Data sets

    Each data set is its own list of values. A step that uses a set gets its 1st value on run 1, its 2nd value on run 2, and so on, so each text box can have a different list.

    No data sets yet Add one, or choose + New data set in a Type text step.
